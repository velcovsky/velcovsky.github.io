Ilogic

iLogic je součást  Autodesk Inventoru, která doprogranovat funkce vylepšující a urychlující návrh, tvorbu a publikování vytvářené dokumentace.
Pomocí pravidel ilogicu lze usnadnit a zautomatizovat řadu rutinních činností konstruktéra.
Pomocí VBA lze rovněž vytvořit vlastní tlačítka v panelu nástrojů, pro snadné zpouštění pravidel.

CODE INJECTOR

Pro spouštění více pravidel najednonou a ve více dokumentech, lze využít také Code injector, které lze stáhnou zde.

Event trigger

Spouštěč událostí anglicky také event trigger umožňuje spouštět pravidla iLogicu automaticky a bez zásahu, například při otevření souboru, uložení souboru, atd.. Spoštění lze nastavit jako projednotlivé soubory, tak pro všechny soubory daného typu. Spouštěč nalezneme na Kartě Správa > iLogic.
