VBA a Autocad

Visual Basic for Applications (neboli VBA) je programovací jazyk od firmy Microsoft. VBA umožňuje vytváření uživatelsky definovaných funkcí, automatizaci procesů, přístup k Windows API apod.  VBA je možné také využít v aplikaci Autocad pro automatizaci rutinních činností.
