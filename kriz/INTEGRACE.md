# Rychlá integrace

Zkopíruj `online.html`, `css/`, `js/` a `krizovky/` do kořene repozitáře `velcovsky/kriz`. Zachovej `kriz.html`.

Online luštění: https://velcovsky.github.io/kriz/online.html

## Přidání křížovky
Nahraj další `.json` do `krizovky/` a commitni změnu do GitHubu. Seznam se získává automaticky z veřejného GitHub API, takže není potřeba upravovat žádný další soubor. Po publikování obnov stránku.
